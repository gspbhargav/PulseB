# PulseB

**Log your life in time pulses.**

PulseB is a minimal Android app that helps you track how you spend your day using configurable time intervals. Every interval, PulseB prompts you to log what you were doing. If you miss a log, the time window escalates until you record an entry.

---

## Features

- ⏱ Configurable interval logging (default 15 minutes)
- 🔁 Intelligent escalation for missed entries
- 🔒 Lock-screen popup logging
- 📝 Smart suggestions based on common activities
- 📊 Timeline view of daily activities
- 📈 Analytics dashboard with time distribution graphs
- 🌙 Dark mode support
- 📤 JSON export
- 💾 Fully offline, local storage

---

## How It Works

1. PulseB prompts you every X minutes.
2. You log what you did in the previous interval.
3. If you ignore a prompt, the interval increases (15 → 30 → 45 → 60...).
4. Once you log an activity, the interval resets.



## Vision

PulseB is designed to be fast, minimal, and frictionless — making time awareness effortless.
